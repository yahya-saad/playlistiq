## Summary

The "YouTube Playlist Duration Calculator" is a lightweight web application that allows users to calculate the aggregate duration of multiple YouTube playlists at various playback speeds. It utilizes a Node.js/Express backend for API key management and metadata caching, and a minimal Alpine.js/Tailwind frontend for instant feedback.

## Technical Context

**Language/Version**: Node.js 18+ / JavaScript (ESM)  
**Primary Dependencies**: Express, axios (for API calls), Alpine.js (via CDN), Tailwind CSS (via CDN)  
**Storage**: In-memory Map for caching playlist metadata (No persistent DB)  
**Testing**: Jest (Supertest for API, JSDOM for frontend)  
**Target Platform**: Node.js Runtime / Modern Browsers
**Project Type**: Web Application (Single Service)  
**Performance Goals**: < 500ms TTI/Latency (Constitution MANDATORY)  
**Constraints**: Zero unnecessary dependencies, < 200ms API p95, No database unless justified (RELATIONAL COMPLEXITY: N/A)  
**Scale/Scope**: Handles aggregate metadata for 100+ videos; no auth or user persistence.
